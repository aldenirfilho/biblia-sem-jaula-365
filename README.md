# 📖🔥 Bíblia Sem Jaula 365 · Códice de Estudo

**ALDENIR ROCHA DE OLIVEIRA FILHO · PROJETO 360X**

> *Entrar na Bíblia sem desligar a inteligência.* Um dia por vez: **ler, pensar, agir** — em cerca de 8 minutos.

🌐 **App:** https://aldenirfilho.github.io/biblia-sem-jaula-365/

✠ **Blog:** [Mensagens que Importam](https://aldenirfilho.github.io/biblia-sem-jaula-365/blog/) reúne estudos bíblicos, leituras inter-religiosas, reflexões do Códice e uma biblioteca de PDFs. O blog também pode ser instalado como app. [Como atualizar o blog](blog/README.md).

## 🧩 O que tem

| | |
|---|---|
| 📅 **Plano** | 365 dias em 52 semanas temáticas + 1 dia de encerramento |
| 📖 **Leitura** | texto bíblico completo de cada dia (4.741 versículos), Almeida 1911 |
| 💡 **Conteúdo** | 3 conceitos (1.095 no total), 1 frase de sabedoria e 1 missão prática por dia |
| 🧭 **Rotas** | 8 caminhos pelo mesmo plano: história, exaustão, injustiça, metal, Jesus, casal, rumo e sabedoria prática |
| ✍️ **Caderno** | progresso, sequência de dias, notas, versículos marcados, backup (exportar/importar) |
| 🔎 **Busca** | em títulos, leituras, conceitos, sabedoria e missões — sem ligar para acentos |
| 📄 **PDFs** | um PDF por semana (`pdf/semana-01.pdf` … `semana-53.pdf`) e o volume completo de 439 páginas |
| 🔤 **Leitura acessível** | letra ajustável, tema Códice (escuro) ou Pergaminho (claro) e fonte OpenDyslexic opcional |
| 📲 **App instalável** | funciona offline depois da primeira abertura (PWA) |

O progresso, as notas e as marcações ficam **só no aparelho** de quem usa (armazenamento local do navegador). Nada é enviado a servidor.

## 🗂️ Estrutura

```
index.html              página do app
assets/app.css · app.js estilo e lógica (sem dependências externas)
assets/emblema.svg      brasão
assets/fonts/           Cinzel, Cormorant Garamond, Lora, Poppins, OpenDyslexic (SIL OFL)
data/estudo.json        plano + textos do dia
pdf/                    53 PDFs semanais + volume completo
icons/ · manifest.webmanifest · sw.js   app instalável e offline
```
